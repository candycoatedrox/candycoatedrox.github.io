Logical Connectives



Symbol Name Read as Description
~ Negation NOT ~P is true when P is false.
^ Conjunction AND P^Q is true only if both P and Q are true.
v Disjunction OR PvQ is true if P, Q, or both are true.
> Conditional IMPLIES P>Q is true unless P but ~Q.
<> Biconditional IF AND ONLY IF P<>Q is true when P and Q are both true or both false.
