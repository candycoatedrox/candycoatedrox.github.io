Used to define metadata for the page.

  • Title: Defines the title of the HTML document, which appears in the browser toolbar, on search pages, etc.
  • Style: Contains CSS that defines style information for this page only.
  • Link: Usually used to link external CSS stylesheets.
  • Meta: Versatile. Can be used to specify multiple kinds of metadata: character set, page description and author, keywords for search engines, viewport, etc.
